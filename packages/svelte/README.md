# @thomasfosterau/effect-svelte

Svelte 5 runes integration for Effect.

## Installation

```bash
npm install @thomasfosterau/effect-svelte effect svelte
```

## Usage

```ts
import {
  provideRuntime,
  useEffect,
  derived,
} from "@thomasfosterau/effect-svelte";
```

See the repository root README for complete documentation.
