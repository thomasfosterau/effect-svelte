Rename the keyed-`Reactivity` hooks to follow the package's `useX` hook naming: `reactiveQuery` is now `useReactiveQuery`, `reactiveStream` is now `useReactiveStream` and `reactiveMutation` is now `useReactiveMutation`. Their signatures and behaviour are unchanged. The old names stay exported as `@deprecated` aliases of the same functions for this minor release and will be removed in the next one, so replace `reactiveQuery(` with `useReactiveQuery(` (and likewise for the other two) when you upgrade. Their option and handle types are renamed to match: `ReactiveOptions` is now `UseReactiveOptions`, and `ReactiveQueryReturn`, `ReactiveStreamReturn` and `ReactiveMutationReturn` are now `UseReactiveQueryReturn`, `UseReactiveStreamReturn` and `UseReactiveMutationReturn`. The old type names stay exported as `@deprecated` type aliases for the same release. `useReactiveMutation`'s TSDoc now documents its error channel, and that it invalidates its keys only when the mutation succeeds. The README describes the naming rule: every hook is `useX`, and the `useReactive*` hooks are the ones that take `Reactivity` keys.
