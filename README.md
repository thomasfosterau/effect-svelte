# effect-svelte

Two packages, `@thomasfosterau/effect-svelte` and `@thomasfosterau/effect-sveltekit`, for using Effect within Svelte components and SvelteKit applications.

**Disclaimer:** This repository has mostly been created using Claude Code and extracts a bunch of utilities I've written for my own (private) projects. Expect the API to churn based on what I need for my own projects before there is a v1.0 release.

## Development

Setup, commands and the pre-PR checklist are in
[CONTRIBUTING.md](./CONTRIBUTING.md). Releases are automated with Changesets
and npm trusted publishing (OIDC); see [docs/RELEASING.md](./docs/RELEASING.md).
